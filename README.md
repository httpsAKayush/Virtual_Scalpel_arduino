# Virtual Scalpel

A Virtual Reality (VR) surgical training simulator developed using **Unity**, **Blender**, and **ESP32**. The project provides an immersive environment for simulating surgical procedures through realistic 3D models, VR interactions, and hardware integration.

---

## Features

- VR-based surgical training environment
- Interactive scalpel-based surgical simulation
- Realistic 3D anatomical models
- Hardware integration using ESP32
- Haptic feedback support
- Real-time object interaction
- Modular and extensible project architecture

## Workflow

1. Design and optimize 3D surgical models in Blender.
2. Import assets into Unity.
3. Develop VR interactions using Unity and C#.
4. Integrate ESP32-based hardware components.
5. Implement scalpel interaction and collision handling.
6. Add haptic feedback for enhanced immersion.
7. Test and optimize performance for smooth VR execution.
